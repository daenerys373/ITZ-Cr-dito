Arquitectura y reglas del simulador

Cómo funciona el simulador multibanco

¿Por qué aparecen bancos de México si no tenemos convenio con ellos?

Como es un proyecto escolar sin conexión real a APIs bancarias, la base de datos incluye una tabla paramétrica (bancos_catalogo) con tasas, comisiones y porcentajes de mora referenciales de 8 bancos en México para que el usuario compare costos reales y decida cuál le conviene.

¿Cómo se calcula la tasa y la mora de cada banco?

Cada banco tiene una tasa base por periodo (ej. Scotiabank 3.1%, BBVA 3.2%, Banco Azteca 5.2%), a la que se suma +1.0% si el monto supera $15,000 y +1.0% si el plazo excede 12 pagos. Si abonas menos que tu cuota, se aplica la mora propia de ese banco sobre el monto faltante.

¿Cómo se emplea la base de datos relacional?

Las tablas bancos_catalogo, clientes, prestamos, amortizacion, pagos y bitacora mantienen integridad referencial (PK/FK) y registran cada movimiento en tiempo real en la sección inferior.

Aviso de privacidad y alcance académico

Los datos personales se enmascaran en el panel de base de datos. Ninguna operación involucra dinero real ni compromisos financieros con instituciones bancarias.
